# Deutsch (.deu) für VS Code

1. Diesen Ordner (`editor/vscode`) nach `%USERPROFILE%\.vscode\extensions\deutsch-sprache` kopieren.
2. VS Code neu starten; `.deu`-Dateien werden als „Deutsch" hervorgehoben.
3. Optional: `npx @vscode/vsce package` im Ordner, dann `code --install-extension deutsch-sprache-0.1.0.vsix`.
